About CareNest

A clear, colorful clinic workflow concept for appointment and record management.

✚
PROJECT OVERVIEW

Making everyday clinic admin feel more organized.

CareNest is a student-built prototype that brings a front-desk schedule, fictional patient profiles and appointment history into one responsive workspace.

⌕THE CHALLENGE

Scattered information

Small teams can find it difficult to keep daily visit times, patient contact details and appointment statuses organized in separate places.

✦THE IDEA

One simple workspace

CareNest groups appointment booking, schedule search and fictional patient record management into a single, easy-to-follow experience.

⌘THE BUILD

Frontend + backend

The responsive interface uses HTML, CSS and JavaScript. A local Node.js API validates requests and stores demo records in SQLite.
